          登録済みの用語（その場で編集できます）

            マイク

            録音に使うマイクを選びます。選択はこの端末に保存され、次回以降の録音に使われます。

            この画面を開いている間、マイクの入力レベルを表示します。話すとバーが動けば正しく拾えています。緑〜黄が適正、赤が続くときはマイクから離れるか音量を下げてください。

            マイクを利用できません。ブラウザのマイク権限を許可してください（HTTPS または localhost が必要です）。

            メール

            ここに入れておくと、メールを作るときに宛先・CCが自動で入ります。

            AI連携

            これを設定すると、録音を止めたときの AI議事録の自動作成 が使えます。録音音声をこのキーで直接 Gemini に送り、議事録＋メールを自動生成します。キーはこの端末内（localStorage）にのみ保存され、他人には共有されません。→ 無料のAPIキーを取得（Google AI Studio）

            「要課金」のモデルは、Google Cloud プロジェクトに請求先が設定されていないと必ず上限エラー（429）になります。無料で使う場合は gemini-3.5-flash を選んでください。

            本日の利用（この端末での推定） 0 / 1,500 回（目安）

            無料枠だけで使う設定手順（課金されない使い方）
            1. Google AI Studio のAPIキー画面を開き、Googleアカウントでログイン（クレジットカード不要）。
            2. 「Create API key」でキーを作成。請求（Billing）は絶対に有効化しない。有効化するとそのプロジェクトは無料枠が消え、1トークン目から課金対象になります。
            3. できたキー（AIza… または AQ.…）を、コピーボタンで全体をコピーして上の欄に貼り付け（画面に出ている省略表示「AQ.Ab8…」を手入力すると無効キー扱いになります）。モデルは gemini-3.5-flash（Flashのみ無料。Proと最新のgemini-3.6-flashは無料枠に割り当てが無く429エラーになります）。貼り付けたら 「キーをテスト」で実際に使えるか確認できます。
            4. 無料枠の上限（1分あたり・1日あたりの回数）はモデルと時期で変わります。正確な残量は AI Studio のキー画面で確認してください。超えても課金ではなく エラー（429）で止まるだけなので、無料枠だけで安全に使えます（上の「本日の利用」はこの端末で数えた目安です）。

            ⚠ プライバシー：無料枠は入力/出力が Googleの製品改善に使われる・人間が確認する場合があります。機密性の高い会議音声の送信は避けてください（学習利用を止めるには有料契約が必要＝無料枠ではなくなります）。

            録音音声と一緒に共有される指示文です。音声から議事録＋メール文面（件名/本文）まで作らせます。このあとに会議名・日付・参加者が自動で付きます。

            録音の診断

            ロック画面に録音中の表示が出ない・ゲージが動かないときに、原因の切り分けに使います（録音中に押すと詳しく分かります）。

            アプリの更新

            アプリ版（APK）でのみ動作します。新しい版が公開されていれば、この画面からダウンロードしてそのままインストールできます。ブラウザで開いている場合は、再読み込みすれば常に最新です。

            このアプリについて

            録音・文字起こし・議事録化・出力をすべてブラウザ内で完結するPoCサンプルです。音声は外部へ送信されません。文字起こしは Transformers.js の Whisper を利用しています。

            初回はモデル（数十MB〜数百MB）のダウンロードが発生します。Wi-Fi環境での初回利用を推奨します。

            使い方マニュアル

            NOTELOOP は、会議を録音するだけで、AIが要約・文字起こし・議事録・メール文面までまとめて作るアプリです。押すボタンは基本的に中央のマイクボタン1つだけです。

            はじめの4ステップ

            1. 1
              録音する

              中央下の丸いマイクボタンをタップ。初回はマイクと通知の許可を求められるので、どちらも「許可」してください。録音が始まると、上に経過時間と音のゲージが出ます。

            2. 2
              話す（画面は見なくてOK）

              話した内容は「文字起こし」として画面に流れます。最初は「準備中」と点が3つ出て、少ししてから文字が出はじめます。途中で止めたいときは右下の一時停止ボタン、画面を消しても録音は続きます（ロック画面の通知から一時停止・完了ができます）。

            3. 3
              もう一度タップして止める

              止めるとAIが自動で仕上げます。画面のいちばん上に進捗ゲージと「完了まで約○分」が出て、できたものから順にカードが現れます（要約 → 文字起こし → 議事録 → メール）。作成中はマイクボタンが隠れます。

            4. 4
              確認して共有する

              各カードの文章はその場で直せます。書き出しやコピーは、枠の右下の「＜」を押すと出てくるボタンから。録音するたびに自動で履歴に残るので、保存の操作は要りません。

            次の会議を録るには：画面のいちばん下までスクロールするとマイクボタンが出てきます。または画面のいちばん上で下へ引き下げて離すと録音待機に戻ります。どちらでも今の内容は履歴に残ります。

            録音後に出てくるカード

            カードは中身ができてから順番に現れます。まだ出ていないものは、AIが作っている途中です。

            • 録音データ録った音声をその場で再生できます。保存したいときはプレーヤー右端の「︙」→ ダウンロードから。
            • 要約AIが付けた短いタイトルと、要約（5行以内）・決定事項・ToDo。まずここだけ読めば、何の会議だったか分かります。
            • 文字起こし録音中は「速報」（速い代わりに粗い文字起こし）。止めたあとAIが録音全体を聞き直し、「AIで高精度化済み」の文章に自動で置き換わります。自分で直したあとは上書きされません。
            • 議事録日時・参加者・決定事項・To-Do・要旨の形にまとめた本文。編集できます。
            • メールそのまま送れる件名と本文。宛先・CCは設定に入れておけば自動で入ります。

            画面の説明

            • 録音中央のマイクボタンで開始／停止（待機中は紫、録音中は赤）。右下のスライダーのアイコンから会議情報（タイトル・日付・参加者）とマイクの選択を開けます。録音中は右下が一時停止ボタンになります。
            • 履歴録音するたびに自動で残ります。カードにはタイトル・日時・録音した時間帯・要約（3行）・録音の長さ・容量が並びます。タップするとその場で開き、音声の再生・議事録・メールまで確認できます（「一覧へ戻る」で戻ります）。カード右下のごみ箱で削除。最大10件です。
            • 設定項目ごとのカードに分かれています。タイトルをタップで開閉し、設定画面を開き直すとすべて閉じた状態から始まります。
            • マニュアルこの画面です。上の目次から各項目へ飛べます。
            • メニュー左上の三本線（PCでは常に左側）から画面を切り替えます。上部に今のバージョンを表示します。

            文字起こしの仕組み（速報 → 高精度）

            「録音中にすぐ出す」ことと「正確に書く」ことは両立しないため、2段階に分けています。

            段階いつ中身
            速報録音中数秒ごとに区切って文字にします。すぐ出る代わりに、人名や固有名詞はぶれます。目安としてご覧ください。
            高精度停止後録音全体をAIが通して聞き直します。前後の文脈が使えるため精度が上がり、話者（A／B）も分かれます。速報を自動で置き換えます。
            議事録・メール停止後同じ音声から、要約・議事録・メール文面を作ります。
            何も話していない録音のとき：AIに送らず「発言が入っていませんでした」と表示します。無音のまま送ると、AIが実際には無い会話を作ってしまうためです。

            設定でできること

            • 文字起こし録音中のライブ表示のオン／オフ、話者の自動判別、録音中の画面常時オンなど。
            • 変換辞書「さくらしょうじ」→「さくら商事」のように、読みや誤変換と正しい表記をセットで登録します。停止後の文字起こし・議事録・メールで自動的に統一されます。
            • マイク使うマイクの選択と、入力レベルの確認。バーが動けばマイクは正常です。
            • メール既定の宛先とCCを入れておくと、メールを作るときに自動で入ります。
            • AI連携Gemini のAPIキー・モデル・指示文と、録音停止後に自動でAI議事録を作成の切替。キーが無いとAIの要約・議事録は作れません（無料で取得できます）。
            • 録音の診断アプリ版のみ。録音中に押すと、通知の許可やマイクの音量が読めているかを確認できます。
            • アプリの更新アプリ版のみ。新しい版があれば、この画面からダウンロードしてそのままインストールできます。

            便利な機能

            • 枠の右下の「＜」文字起こし・議事録・メール本文の枠の右下にあります。押すとボタンが左へ開きます（もう一度で閉じます）。コピー／用語修正／情報編集／ダウンロード（.txt・Word・.md）／作り直すがここにまとまっています。
            • 用語修正誤変換されやすい語を、文字起こし・議事録・メール本文をまとめて一括置換できます。そのまま辞書に登録すれば、次回から自動で直ります。
            • 会議情報タイトル・日付・参加者（部署＋氏名）は録音の前でも後でも入力でき、議事録やメールに反映されます。タイトルを入れなかった場合は、AIが内容から短い題を付けます。
            • 引き下げてリセット画面のいちばん上で下へスワイプすると丸い矢印が出ます。引いて離すと録音待機に戻ります（今の内容は履歴に残ります）。
            • ロック画面の通知アプリ版は画面を消しても、通知に音量のゲージ・録音時間・一時停止／録音完了が出ます。通知だけで操作でき、アプリは前面に出ません。
            • 録音の自動復帰画面を消している間に録音が止まっても、自動で録り直して1本に繋ぎ直します。それでも足りなかったときは「録音データ」に⚠と実際の長さを表示します。
            • 作成中も画面を消せる録音を止めたあとの文字起こし・議事録づくりは、画面を消しても続きます。作っている間は通知に進捗バー・進捗率・完了までの目安時間が出るので、ロック画面のまま待てます。できあがると完了のお知らせが届きます。
            • あとから作り直す議事録ができていない録音は、履歴のカードに「議事録が未作成」「作成が途中で止まりました」と表示され、その場のボタンで作り直せます。保存してある録音音声から作るので、録り直しは要りません。
            • アプリとして使うアプリ版（APK）が最も安定します。ブラウザ版でも「ホーム画面に追加」で独立したアプリのように起動できます。

            データとプライバシー

            • 保存先議事録・設定は端末内（localStorage）、録音音声は端末内（IndexedDB）に保存されます。アプリの提供者へ送られることはありません。
            • AIへ送るもの要約・高精度文字起こし・議事録を作るとき、録音音声が Google の Gemini へ送信されます。外部へ出したくない録音では、設定 → AI連携の「自動でAI議事録を作成」をOFFにしてください。
            • APIキー入力した Gemini のキーはこの端末内だけに保存されます。
            • 削除履歴カードのごみ箱で、議事録と録音音声をまとめて削除できます。

            困ったとき（FAQ）

            録音中に文字が出てこない

            「準備中」のまま数十秒かかることがあります。設定 → 文字起こし で「録音中のライブ文字起こし」がONか、AI連携にAPIキーが入っているかを確認してください。文字が出なくても録音は続いています。止めたあとにAIが全体を文字起こしするので、記録は残ります。

            話していないのに文字起こしや議事録が出る

            Ver.8.7 で対策済みです。録音に発言が入っていない場合はAIに送らず、「発言が入っていませんでした」と表示します。それでも身に覚えのない内容が出たときは、設定の変換辞書に不要な語が登録されていないか確認してください。

            人名や社名がまちがって書かれる

            設定 →「変換辞書」に正しい表記を登録してください。停止後の文字起こし・議事録・メールで自動的に統一されます。すでに出ている文章は、枠の右下「＜」→「用語修正」でまとめて置換できます。

            要約や議事録が作られない

            設定 → AI連携 に Gemini のAPIキーが必要です。キーを入れたら「キーをテスト」で確認してください。無料枠を使い切った場合は、しばらく待つか別のモデルを選ぶと通ります。

            作成の途中で画面を消したら、文字起こしが「速報」のまま止まった

            Ver.9.0 で対策済みです。録音を止めたあとのAI処理も、画面を消したまま最後まで続くようになりました（作成中は通知が出ます）。それより前の版で途中まで作られたものや、通信が切れて止まったものは、履歴のカードに「作成が途中で止まりました」と出て、その場のボタンから作り直せます（保存された録音音声から作るので、録り直しは要りません）。

            画面を消すと録音が止まる

            アプリ版は画面を消しても録音を続けます（通知が出ている間は動いています）。止まってしまう場合は、端末の設定でバッテリー最適化の対象からNOTELOOPを外し、設定の「録音中は画面を常時オン」もONにしてください。

            録音時間より音声が短い

            省電力機能が音声の取り込みを止めた場合に起こります。自動で録り直して繋ぎ直しますが、足りなかったときは「録音データ」に⚠と実際の長さを表示します。長い会議では、画面常時オンをON・バッテリー最適化の除外・録音中は他のアプリに切り替えない、の3点で安定します。

            マイクのバーが動かない

            設定 →「マイク」または会議情報の画面で確認できます。バーが動かないときは、端末の設定でNOTELOOPのマイク権限が許可されているか確認してください。

            ロック画面に録音中の表示が出ない

            端末の設定 →「アプリ」→ NOTELOOP →「通知」で通知が許可されているか、通知チャンネル「録音」がオフになっていないかを確認してください。録音を始めたときに画面上部へ案内と「通知の設定を開く」ボタンが出ます。

            最新版に更新したい

            アプリ版は 設定 →「アプリの更新」→「更新を確認」から、その場でダウンロードしてインストールできます。ブラウザ版は再読み込みで最新になります。今の版はメニュー上部に表示されます。

            「パッケージが既存のパッケージと競合するため…」と出る

            入っているアプリと新しいAPKの署名が違うときに出ます（Ver.6.3 より前の版から更新する場合）。一度アンインストールしてから入れ直してください（設定・履歴・APIキーは消えます）。Ver.6.3 以降は署名を固定したので、以後はそのまま上書きできます。

            対応環境・注意

            • おすすめAndroid はアプリ版（APK）が最も安定します。ブラウザで使う場合は Chrome 系を推奨します。
            • ネット接続AIの要約・文字起こし・議事録にはインターネット接続が必要です。録音そのものはオフラインでもできます。
