# NOTELOOP — 議事録自動化Webアプリ（PoCサンプル）

ブラウザだけで完結する議事録自動化アプリです。**録音 → その場で文字起こし → 議事録に整形して編集 → txt / Word / メール下書きで出力** までを、サーバやGPUなしで動かせます。

> これは「実装設計資料（方式A）」を個人が手元で体感するための **PoC（試作）サンプル** です。
> 文字起こしはブラウザ内Whisper、議事録化は AI（Gemini）で行います。本番の重い部分（サーバ側 faster-whisper など）は後から差し替える前提です。

---

## 目的

添付「実装設計資料」の**方式A**（ブラウザ録音 → 文字起こし → 議事録化 → 出力）を、
サーバ・GPUを立てずに**クライアント完結**で一通り動かせる状態にすること。

## 特長

- 📲 **アプリとしてインストール可能（PWA）**: ホーム画面/デスクトップに追加して、独立したアプリのように起動できます（下記「アプリとしてインストール」参照）。
- 🇯🇵 **日本語専用**: 文字起こし言語は日本語に固定（設定不要）。
- 📱 **メニュー形式のUI**: 左上のハンバーガー（三本線）から**左スライドのドロワーメニュー**で **録音 / 履歴 / 設定 / マニュアル** を切り替え。ホームは**中央下部に固定のマイクボタン**と点滅する案内だけのミニマル構成。
- 📊 **音量で動くゲージ**: 録音中は上部に、**声の大きさに合わせて縦のバーが非対称に伸び縮みするゲージ**を表示（無音のときは点になって流れます）。アプリ版では録音サービスの振幅を使うため、マイクを二重に開かずに動きます。
- 🎙 **録音**: ブラウザの `MediaRecorder` / `getUserMedia`。経過時間・音量ゲージ・録音の再生。
- 📥 **外部で録音した音声の読み込み**: ICレコーダーや他の録音アプリで録った音声ファイル（m4a / mp3 / wav / aac / ogg / opus / webm / mp4 など）を読み込み、**録音を止めたときとまったく同じ流れ**で議事録＋メール文面を自動作成。読み込んだ音声も履歴に保存されます。
- 🗣 **2つの録音モード（スマホのマイク制約に最適化）**: Android では `getUserMedia`（録音）と Web Speech が**同時にマイクを使えない**ため、モードを分けています。
  - **ライブ字幕モード（既定・ON）**: **Web Speech API** でリアルタイム字幕を表示（日本語高精度・端末負荷ほぼゼロ）。録音中の音声はクラウド（Google）へ。対応端末では音声も同時に保存し、停止後はその音声から AI 議事録を作成します。
  - **録音モード（OFF）**: 字幕なしで**音声を保存**。停止後に **「音声をAIに送る（Gemini）」** で高精度な議事録＋メール（推奨）。
  - Web Speech 非対応・オフライン時は自動で録音モードに。**CPUで動くWhisperのライブ表示（「！！！」等の誤認識・詰まりの原因）は廃止しました。**
- ⚡ **任意のオフライン確定（Whisper）**: 設定で「停止後にWhisperで文字起こし」を選ぶと、[Transformers.js v3](https://github.com/huggingface/transformers.js) で端末内文字起こし。PCでは **WebGPU** で高速化（モバイルは不安定なため自動でWASM）。エンコーダ fp32 ＋ デコーダ q4 のハイブリッド量子化を使用。
- 🤖 **AI連携**:
  - **AIで議事録を作成（自動・BYOK / おすすめ）**: 設定に自分の **Gemini API キー**（[無料取得](https://aistudio.google.com/apikey)）を入れておくと、ワンタップで録音音声を **Gemini API に直接送信 → 議事録＋メール文面を自動生成**。サーバー不要（ブラウザから直接呼び出し）。キーは**この端末内（localStorage）にのみ保存**。長い音声は Gemini Files API で自動アップロード。音声は 16kHz mono WAV に変換して送信（形式互換のため）。
  - **音声をAIに送る（手動・キー不要）**: 録音音声を **OS共有シート**で Gemini アプリ等へ共有、または DL＋Gemini を開く。指示文はコピー済み。
  - 指示テンプレートは設定で編集可能。
- 📝 **議事録の編集**: AIが作った議事録＋メール文面はその場で編集でき、そのまま書き出し・メール本文になります。要点／決定事項／ToDo の下書き欄も任意で使えます。
- 📤 **出力**: `.txt` / `.md` / `.docx`（Word, [docx](https://github.com/dolanmiu/docx) をブラウザで利用）。
- ✉️ **メール作成**: 議事録（AI生成 or 貼り付け）からメールを作成し、**既定メーラー（Thunderbird等）/ Gmail / Outlook のWeb作成画面 / .eml** で件名・本文入りで開けます。
- 🔤 **用語の確認・修正**: 会社名など誤変換されやすい語を**一括置換**（辞書に登録すると録音後に自動チェック→ポップアップ）。
- 🔘 **段階変化する録音ボタン**: 録音 → 文字起こし中 → 議事録作成 → メール、と状況に応じてアイコン・動作が変化。
- 🎧 **音声ファイル出力（AI共有向け）**: 録音した音声をダウンロード。**m4a に対応したブラウザでは自動的に .m4a**（AIへの共有に扱いやすい圧縮形式）で保存し、非対応ブラウザでは最適な形式にフォールバック。加えて、どのAI/ツールでも読める **WAV** にも変換できます。
- 💾 **録音後に自動保存**: 録音を止めると、文字起こし・（Whisper時は）音声・会議情報を**自動で履歴に保存**（最大10件、古いものから削除）。
- 👥 **会議情報の入力**: タイトル・日付・**参加者（部署＋氏名）**を録音の前・最中・後いつでも入力可能（部署は一覧から選択、または手入力で追加）。出力・AI連携・履歴にも反映。
- 🗂 **過去の議事録一覧**: 議事録は localStorage、録音音声は IndexedDB に保存・呼び出し。履歴カードから音声もダウンロード可能。

### 文字起こしエンジンを選べます（設定 → 文字起こしエンジン）

| エンジン | 精度 / 速度 | プライバシー | 備考 |
|---|---|---|---|
| **ブラウザ内Whisper**（既定） | モデル次第・停止後に高精度化（**WebGPUなら高速**） | ◎ 端末内で完結・**外部送信なし**・オフライン可 | 初回にモデルDL。停止後に音声全体を再処理（進捗・残り時間を表示）。small〜large-v3-turbo で高精度 |
| **Web Speech API** | ○〜◎ **リアルタイム高精度**・待ち時間ほぼ無し・端末負荷ゼロ | △ 音声が**ブラウザ経由でクラウドへ送信**（Chrome=Google / Edge=Azure）・**要ネット** | モデルDL不要。マイク競合を避けるため**このモードでは録音音声(m4a)は保存されません**（音声も残したい場合は Whisper） |

> どちらのエンジンでも、録音音声（m4a等）の保存・AI連携・各種書き出しはそのまま使えます。**外部送信を避けたい実データはブラウザ内Whisper**、**手軽さ・リアルタイム精度を優先する検証は Web Speech API** が向いています。

### 精度を上げたいときは（ブラウザ内Whisper）

**設定 → 高精度モデル** を大きいものに変えてください（遅くなりますが精度が上がります）。

| モデル | サイズ目安 | 精度 / 速度 |
|---|---|---|
| tiny | 約40MB | 控えめ / 最速 |
| base | 約80MB | 標準 / 速い |
| **small（既定・おすすめ）** | 約250MB | 高精度 |
| large-v3-turbo | 約1.2GB | 最高精度・WebGPU/PC推奨（メモリ16GB＋） |

> turbo は端末メモリを多く使うため、スマホ（特に低価格機）では動かない場合があります。まずは **small** を、GPU搭載PCでは **large-v3-turbo × WebGPU** をお試しください。設定の「実行バックエンド」で WebGPU/WASM/自動 を選べます。

**精度が出ないとき（「このように…」等の反復が出る場合）:**
- Whisper は無音・小音量で文字列を反復（ハルシネーション）しがちです。本アプリは反復抑制（`no_repeat_ngram_size`）と後処理で自動的に抑えていますが、**マイクに近づける／端末の録音音量を上げる**と大きく改善します。音量が小さいと警告を表示します。
- 静かな環境で、はっきり話すほど精度が上がります。それでも厳しい場合は高精度モデルを **large-v3-turbo（WebGPU / PC推奨）** に上げてください。

## 使い方

1. **🎙 録音** 画面で **中央の丸いボタン** をタップ → マイクを許可 → 会議を録音。録音中は上部のゲージが**声の大きさに合わせて**動きます。
   - すでに別の機器・アプリで録った音声があるときは、マイクボタンの上の **「録音済みの音声ファイルから作成」** から読み込めます（以降の流れは録音と同じ）。
   - **設定** で AI連携（APIキー・モデル・指示文）やライブ字幕、Whisper の各種設定を変えられます。言語は日本語固定です。
2. もう一度ボタンをタップして **停止** → そのまま音声が AI（Gemini）へ送られ、**議事録＋メール文面が自動作成**されます（数十秒）。結果はその場で編集でき、メール本文にも反映済みです。
3. **書き出し / メール**: 議事録ができると下にカードが現れます。`.txt` / `.md` / `.docx` / **メール下書き** で書き出し、**💾 一覧に保存** で **🗂 履歴** に残せます。
4. 必要なら **🎧 音声を保存 / WAVに変換** で録音音声もダウンロードできます。

> 動作確認はマイク録音・WASMの相性から **Chrome系ブラウザ** を推奨します。

### 🤖 AI議事録までの流れ（3ステップ）

1. **録音する**（またはマイクボタンの上の「**録音済みの音声ファイルから作成**」で外部の音声を読み込む）。
2. **止める** → そのまま音声が Gemini へ送られ、**議事録＋メール文面が自動生成**されます。
   自動で作らせたくないときは **設定 → AI連携 →「録音・読み込みのあと自動でAI議事録を作成」** をOFFにし、**「AIで議事録を作成」** ボタンで作成します。
3. **出力・共有**: 議事録ができると **書き出し** と **メールを作成** のカードが現れます。`.txt` / `.md` / Word / メール、**一覧に保存**で履歴へ。

- APIキーを使わない場合は、議事録カードの **「APIキーを使わず手動でAIに渡す」** から、音声の共有＋指示文のコピーで Gemini などに渡せます。
- 指示テンプレートは **設定 → AI連携** で自由に編集できます（「既定に戻す」も可）。

## アプリとしてインストール（PWA）

公開URL（HTTPS）を開くと、ブラウザから「アプリ」としてインストールできます。インストールすると、ホーム画面/デスクトップのアイコンから、アドレスバーのない独立ウィンドウで起動します。

- **Android（Chrome）**: メニュー（⋮）→「アプリをインストール」または「ホーム画面に追加」。
- **iPhone/iPad（Safari）**: 共有ボタン → 「ホーム画面に追加」。
- **PC（Chrome / Edge）**: アドレスバー右のインストールアイコン（⊕ / モニタ型）→「インストール」。

インストール後もオフラインで**アプリ画面自体は起動**します（初回に取得済みのモデルはブラウザのキャッシュを使います。未取得のモデルのダウンロードにはネットが必要です）。

> 実体は `manifest.webmanifest` と `sw.js`（Service Worker）による PWA です。

| ファイル | 役割 |
|---|---|
| `index.html` | 画面（録音 / 議事録 / 履歴のUI） |

### 議事録化は「音声 → Gemini」に一本化

以前はアプリ内のルールベース処理（`generateMinutes`）や、文字起こしを Claude へ渡す経路もありましたが、
**録音音声をそのまま AI に渡すのがいちばん精度が高く、手順も少ない**ため、
`app.js` の `geminiGenerateMinutes()` / `runAiAutoMinutes()` に一本化しました（Claude 連携は廃止）。
録音を止めた直後、または音声ファイルを読み込んだ直後に自動で走り、議事録＋メール文面までを1回の生成で作ります。

生成結果（`#aiResult`）はそのまま `.txt` / `.md` / Word の書き出しとメール本文に使われます。
議事録の下書き欄（要点／決定事項／ToDo）は、手入力・貼り付け用の**任意の入力欄**として残してあり、
入力があるときはそちらが書き出しに使われます。

書き出し・メールのカードは**議事録の中身ができてから**現れます（それまで画面に出さないことで、待っている間の情報量を減らしています）。

文字起こしは `worker.js` に分離しているため、将来サーバ側 `faster-whisper` + WebSocket へ移行しやすい構成です。

## 注意・前提

- **精度**: サンプルは小さいモデル（tiny/base）のため精度は本番より低め。用途は「一連の流れの検証」と割り切ってください。
- **初回ダウンロード**: モデルのダウンロード（数十MB〜）が発生します。以降はブラウザにキャッシュされます。
- **CDN依存**: Transformers.js と docx を CDN から読み込みます（オンライン環境が必要）。
- **メール下書き**: `mailto:` は本文長に制限があるため、長い議事録は末尾が省略されます（全文は txt / Word をご利用ください）。
- **公開範囲**: GitHub Pages は公開URLになります。実会議の実データは載せず、ダミー音声で検証してください。

## 技術メモ

- 文字起こし用の音声は `AudioContext`（16kHz mono）で取得し、数秒ごとに Web Worker の Whisper へ渡して逐次表示します。
- 再生用の音声は `MediaRecorder` で別途保持します（フィードバック防止のため、解析用ノードは gain 0 経由で接続）。
- 本資料・実装は 2026年7月時点の一般的理解に基づく検討用です。各ライブラリ・サービスの最新情報と利用規約は実施時にご確認ください。

## Androidアプリ（APK）版

ブラウザ版に加えて、Androidアプリとしてビルドできます。中身は同じWebアプリ
（Capacitor でネイティブに包んでいます）ですが、**録音だけはネイティブの
フォアグラウンドサービスで行う**ため、画面を消しても他のアプリに切り替えても
OSに録音を止められません。長時間の会議で音声が途中までしか残らない問題は、
このアプリ版で解消します。

### APKの入手（スマホから1タップ）

**https://github.com/tcta-tottori/NoteLoop/releases/latest/download/NOTELOOP.apk**

このURLを**Chromeアプリで直接**開いてください（GitHubアプリ内のブラウザからだと
保存されないことがあります）。落ちてきたファイルをタップしてインストールします。
「提供元不明のアプリ」の許可を求められたら許可してください。

**Chromeが「危険なファイル」としてAPKを消してしまう場合**は、次のどちらかで回避できます。

- Chrome の ⋮ →「ダウンロード」を開き、ブロックされた `NOTELOOP.apk` の
  ⋮ →「ダウンロードを続行」（システムの「ファイル」アプリには出ません）
- zip版を使う: https://github.com/tcta-tottori/NoteLoop/releases/latest/download/NOTELOOP-apk.zip
  （中身は同じAPK。展開してからタップ）

`main` へpushするたびに GitHub Actions がビルドし、上のURLの中身が
最新版に差し替わります。手動で走らせる場合は Actions 画面の
**Run workflow** から実行できます。

PC から取る場合は Actions の実行結果にある **Artifacts → NOTELOOP-apk**
（zip）でも入手できます。※GitHubのモバイルアプリからは成果物を
ダウンロードできないので、上のReleaseのURLを使ってください。

### 手元でビルドする場合

Android SDK（cmdline-tools / platform 34 / build-tools）と JDK 17以上が必要です。

```bash
npm ci
npm run build          # www/ に配信用ファイルを集める
npx cap sync android   # Android プロジェクトへ反映
cd android && ./gradlew assembleDebug
# → android/app/build/outputs/apk/debug/app-debug.apk
```

Web側を変更したら `npm run sync` で APK 側へ反映されます。

### ブラウザ版との違い

| | ブラウザ版 | アプリ版 |
|---|---|---|
| 録音 | MediaRecorder（OSに止められることがある） | フォアグラウンドサービス（止まらない） |
| ライブ字幕 | Web Speech で表示 | 使わない（音声をAIに送って議事録化） |
| 音量ゲージ | あり（Web Audio の解析） | あり（録音サービスの振幅を使用） |
| 更新 | 再読み込みで自動 | APKの入れ替え |

アプリ版でも設定・履歴・Gemini連携はブラウザ版と同じです（データは端末内に保存されます）。
